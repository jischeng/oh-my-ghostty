# OMG 0.22.1 · Ghostty 1.4.1-dev

OMG 0.22.1 is a macOS compositor stability patch release on **Ghostty `1.4.1-dev`** (`7a8ff4d99`) that eliminates Mission Control (`调度中心`) behind-window blur and Liquid Glass flickering on multi-Space setups while hardening window backdrop layer composition and idle input efficiency.

## Highlights

- **Deterministic Mission Control (`调度中心`) multi-Space blur flicker elimination (`MissionControlPresentationMonitor`).** On macOS 26/27, SkyLight suspends live behind-window `CABackdropLayer` wallpaper sampling inside Mission Control when a display hosts Fullscreen Spaces in the top Spaces bar, causing translucent windows (`NSVisualEffectView(.behindWindow)` or `macos-glass-*`) to wash out to a milky gray Exposé fallback and ping-pong on internal layer commits (such as cursor blink or tab breathing). `MissionControlPresentationMonitor` detects Mission Control and App Exposé via locale-independent `Dock` overlays and Quartz multi-display `WindowManager` top Spaces strips (including vertically stacked monitors) while ignoring menu-bar Control Center, Spotlight, and normal desktop Dock containers:
  - Synchronously switches terminal, Quick Terminal, Editor workspace, split, and native auxiliary chrome hosts to quantized solid theme-matched backing, detaches behind-window blur and glass views, pauses decorative tab-icon breathing animations during Exposé, and immediately restores live behind-window blur on exit.
  - Installs zero timers and zero event monitors whenever all OMG windows are opaque, occluded, miniaturized, in native fullscreen, or closed, and restricts active local `NSEvent` monitoring strictly to trackpad swipes and Mission Control / `Control+Arrow` shortcuts so pointer movement, scrolling, and terminal readline `Control` keystrokes (`Ctrl+C`, `Ctrl+A`, `Ctrl+E`, etc.) incur zero WindowServer probes or wakeups.
- **Compositor & `NSVisualEffectView` layer-tree cleanups.**
  - **Quick Input backdrop lifecycle (`AgentQuickInput`)**: Unmounts hidden `.withinWindow` `NSVisualEffectView` backdrops whenever the Quick Input composer is closed (`isBackdropActive: model.isPresented`) while keeping `ComposerTextView` draft/undo state mounted, and falls back to opaque theme chrome during Mission Control.
  - **Wrapper-clipped terminal backdrop (`TerminalBackdropBlurView`)**: Applies corner radius and bounds clipping on an outer wrapper `clipView` rather than mutating `NSVisualEffectView`'s private `CABackdropLayer`, supplies a subtle theme-matched tint when `background-blur < 20`, replaces `.clear` window `backgroundColor` with a `0.001`-alpha theme-tinted backing (`TerminalWindow`, `QuickTerminalController`), and guards blurred windows against AppKit layer-tree auto-flattening.
  - **Auxiliary native surface stability (`OMGNativeTheme` & `OMGNativeSurfaceView`)**: Preserves configuration-level `wantsBehindWindowBlur` intent across temporary Mission Control opaque overrides so sole auxiliary dialogs (`OMGNativeDialog`, `EditorFilePicker`, `SessionRuntimeLibrary`, `GitIntegrationDialog`) never oscillate eligibility on watchdog ticks, and aligns `macos-glass-*` non-opaque window backing at unit opacity (`opacity == 1.0`).

## Version and distribution

- OMG **0.22.1**, bundle version **63** (`CFBundleVersion`).
- Ghostty **1.4.1-dev**, revision `7a8ff4d992edd2aad7537e5bef73ec911aa126bf` (unchanged from `0.22.0`).
- Includes all OMG changes since the published `v0.22.0` tag (`c71896183` → `f8b1399a8`).
- macOS release apps and DMGs are **persistently self-signed (`OMG_SIGNING_MODE=self-signed`); not notarized**, using the same pinned release certificate and designated requirement across `OMG.app`, Sparkle helpers, `DockTilePlugin`, and nested `session-runtime` Mach-O binaries.
- **First-launch Gatekeeper & signer trust note**: Because apps and DMGs are not notarized, macOS Gatekeeper may block the first launch. Users who trust the downloaded app can review and allow it once in **System Settings → Privacy & Security**, and optionally install one-click Code Signing trust via **OMG → Settings → Plugins → OMG Doctor → Trust Release Signer for Updates** (or `omg +doctor`) to preserve TCC grants across updates (migrating from older ad-hoc builds may prompt once; never disable Gatekeeper globally). Sparkle updates retain their separate EdDSA signature on the `universal` DMG enclosure (`SUEnableAutomaticChecks` remains `false`).
- Each `arm64`, `x86_64`, and `universal` macOS app bundles `Contents/Resources/session-runtime` containing the universal local `omgd` relay, `omg-mobile-support`, `askpass`, `macos-aarch64` / `macos-x86_64` and `linux-x86_64` / `linux-aarch64` (`libghostty-vt.so.1`) remote session runtime artifacts, post-sign SHA-256 `manifest.json` files, `revision` (`ad43611eb342d95e271c`), and `snapshot-revision` (`7abe5365444c63ee8df6`). Existing remote `omgd` daemons owning live PTYs are never overwritten in place; older hosts without `durable-close/1` retain pending-close compatibility limits.
- iOS physical device installation requires signing with the user's own Apple ID (a free Personal Team Apple ID works via `OMG-Mobile-0.22.1-ios-installer.tar.gz`, or via SideStore / AltStore / Sideloadly using `OMG-Mobile-0.22.1-ios-unsigned.ipa` and `altstore-source.json`).
