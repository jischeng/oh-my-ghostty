# OMG 0.24.0 · Ghostty 1.4.1-dev

OMG 0.24.0 adds an Inbox view and automatic conversation titles for Agent tabs, docks Quick Input in-flow per split pane with directory-shared sent history, hardens Claude Code status and hook tracking across split panes, and self-heals macOS local `omgd` wrapper attribution across in-place app upgrades.

## Highlights

### Agent Tabs: Inbox View & Conversation Titles

- **Vertical Tab Inbox view.** A new **Inbox** toggle in the vertical tab sidebar header groups workspace tabs into **Continue**, **Today**, **Yesterday**, and **Earlier** by recent activity or creation time. Inbox ordering is strictly display-only: native tab order, tab groups, and keyboard shortcut indices remain unchanged when switching back to **Tabs**, and drag reordering is disabled while viewing Inbox.
- **Conversation-based Agent tab titles.** Agent tabs are now titled after their active `(agent, conversation ID)` instead of their working directory, updating automatically when a pane starts or resumes another conversation while preserving manual tab renames and leaving plain shell tabs untouched. Titles resolve first from the Agent's own session title (including Claude Code `ai-title` and `custom-title` records locally and over SSH), then an optional AI-generated title from the first prompt, and finally the truncated first prompt. Conversation-titled rows display the directory—or SSH host and directory—on a subtitle line.
- **Optional AI title generation (`Features/AI`).** **Settings → Agent** can configure an OpenAI-compatible or Anthropic HTTP endpoint to summarize first prompts into concise tab titles. API keys are stored in an owner-only (`0600`) file outside `settings.json`, prompts are redacted for common secrets before transmission, local plain-HTTP endpoints are supported via `NSAllowsLocalNetworking`, and nothing is sent over the network unless an endpoint is explicitly configured.

### Quick Input

- **Per-pane in-flow dock without `SIGWINCH` or scroll jumps.** Quick Input now docks in-flow directly beneath the active split pane's terminal viewport without triggering unnecessary shell `SIGWINCH` reflows or scrollback jumps, automatically falling back to a floating card when a pane is shorter than the minimum docked height. Alternate-screen TUI apps receive committed terminal grid resizes cleanly, and the docked container matches the terminal background.
- **Directory-shared Sent History with per-pane retention.** Added `keyboard.quickInputHistoryShareByDirectory` (enabled by default, with a one-click folder toggle pill in the History bar). Sessions in the same normalized directory (isolated between local paths and per-SSH-host paths) share sent history while each pane retains its own prior history after changing directories, collapsing identical duplicate texts to the newest visible entry.
- **Explicit Antigravity (`agy`) draft import and preflight feedback.** Enabled explicit toolbar `Ctrl+G` draft import for Antigravity (`agy`) in `auto` mode both locally and over SSH, and replaced silent preflight guard returns in local and remote draft import with localized status messages in Quick Input.

### Claude Code Status & Split-Pane Badges

- **Accurate Claude Code v2.1.295+ status and detached hook ownership.** Canonicalized native OSC 7501 `app=claude-code` (and `agy`) activity reports in `session-runtime` and macOS without inserting nil-agent records that previously suppressed Tier 3 title spinners. Extended executable detection to versioned `claude/versions/*` Mach-O binaries, walked detached `setsid()` hook ancestry up to 32 hops (`_omg_agent_status_v15` with ancestor `--pid`) so short-lived `/bin/sh` hook wrappers no longer flash false crash errors or clear resume descriptors, surfaced explicit Tier 2 `StopFailure` and `AskUserQuestion`/`ExitPlanMode` attention states cleanly, and prevented `SIGHUP`/`SIGINT`/`SIGTERM` (`129`/`130`/`143`) subshell exits from synthesizing false failures.
- **Split-pane Agent badges and popover indicators.** Unfocused split panes now contribute Agent icons, `preferredAgentActivity` badges, and multi-pane tooltips to tab chrome, and native action popover menus render trailing selection checkmarks alongside leading item icons.

### Session Runtime & macOS Upgrade Continuity

- **Self-healing local `omgd` wrapper rotation after in-place `.app` updates.** Recorded the `launchd` wrapper mode, PID, executable path, and `(st_dev, st_ino)` file identity in `HostIdentity` and mobile `GatewayRecord`. Local host and background mobile gateway health checks now verify the live parent `+internal-runtime-host` wrapper PID, `proc_pidpath`, and on-disk inode before reusing a broker, performing seamless in-place takeover (adopting live `session-holder` PTYs without interrupting running shells) whenever Sparkle or `install-dev.sh` replaces the `.app` bundle on disk. Existing `host-local` brokers also step down proactively on poll ticks, before new holder spawns, and via Sparkle's `willInstallUpdateOnQuit` hook and CLI session launchers so macOS `tccd` bundle attribution and folder permissions remain intact across updates.

## Version and distribution

- OMG **0.24.0**, bundle version **68** (`CFBundleVersion`).
- Ghostty **1.4.1-dev**, revision `7a8ff4d992edd2aad7537e5bef73ec911aa126bf` (unchanged from `0.23.2`).
- Includes all changes since the published `v0.23.2` tag.
- macOS release apps and DMGs are **persistently self-signed; not notarized**, using the same pinned `OMG Release Signing` certificate (`9b2e176c03e5458e6fdaf73392cd9d79203972c6`) and designated requirement as `v0.23.2`. macOS Gatekeeper may block the first launch; users who trust the download can review and allow it once in **System Settings → Privacy & Security**, and can optionally install Admin CodeSigning trust via **OMG → Settings → Plugins → OMG Doctor** so Sparkle updates preserve macOS TCC grants seamlessly (migration from older ad-hoc builds may require one-time authorization). Do not disable Gatekeeper globally. Sparkle updates retain their separate EdDSA signature on the universal DMG enclosure.
- The `arm64`, `x86_64`, and `universal` macOS apps bundle `Contents/Resources/session-runtime`, including the universal local `omgd` relay, mobile support helper, and macOS (`x86_64`, `aarch64`) plus Linux (`x86_64`, `aarch64`) remote session runtime artifacts. The session runtime revision is `bfc43814f2b8931317ba` (updated from `8e8d42c58b3ddd438eb3` in `0.23.2`), and the snapshot revision `7abe5365444c63ee8df6` is unchanged from `0.23.2`. A remote daemon that owns live sessions is never replaced in place, so existing remote sessions stay on the revision they started with; older remote hosts without `durable-close/1` cannot acknowledge durable Close requests, and macOS plus Linux hosts without supported systemd/lingering user cgroup v2 retain process-group-only cleanup.
- iOS physical device installation requires signing with the user's own Apple ID (a free Personal Team Apple ID works via `OMG-Mobile-0.24.0-ios-installer.tar.gz`, or via a sideloader / AltStore / SideStore using `OMG-Mobile-0.24.0-ios-unsigned.ipa` and `altstore-source.json`).
