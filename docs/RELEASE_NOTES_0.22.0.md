# OMG 0.22.0 · Ghostty 1.4.1-dev

OMG 0.22.0 synchronizes Oh My Ghostty with upstream **Ghostty `1.4.0` and `1.4.1-dev`** (`1.3.2-dev` `9ae02a326` → `1.4.1-dev` `7a8ff4d99`), upgrading the toolchain and terminal core to **Zig `0.17.1`** and **`libghostty-vt` `1.0.1`** while preserving two-parent merge history and all OMG workspace, Git, Editor, Inspector, Quick Input, Session Runtime, and Mobile capabilities.

## Highlights

- **Upstream Ghostty `1.4.0` → `1.4.1-dev` synchronization (`9ae02a326` → `7a8ff4d99`).** Brings OMG up to current upstream Ghostty across three merge batches, adopting **Zig `0.17.1`**, Unicode 18 (`uucode`), `z2d` `v0.13.2`, `wuffs`-backed Kitty PNG/zlib decompression, and the frozen **`libghostty-vt` `1.0.1`** C ABI (`assume_nonnull` / `GHOSTTY_NULLABLE` headers, sized option/callback structs, and versioned ELF symbol exports).
- **Terminal core, search, Kitty clipboard, and synchronized output.** Includes Ghostty 1.4's multithreaded scrollback & viewport **terminal search** engine, **Kitty clipboard protocol (`OSC 5522`)**, **synchronized output (`mode 2026`) render hold** in `libghostty-vt`, Kitty graphics snapshot serialization & render-state placement/animation tracking, `OSC 3008` hierarchical context bridged with OMG `context_signal` and `OSC 7501` program status (rev 0.4), `DECSTR` / `DECRQCRA` (`XTCHECKSUM`) / `DECIC` / `DECDC` / `DECBI` / `DECFI` / `DECXCPR` / `CSI 8 t` & `CSI 19 t` support, packed `u128` `Style` with SIMD/mixed-width print fast paths, and `RenderState` overscan smooth scrolling integrated with OMG's two-tier GPU memory trimming and optional `SwapChain`.
- **macOS 27 Glass, window-theme switching, and Sparkle `2.9.6`.** Integrates upstream `TerminalGlassView` and macOS 27 tab bar frame/opacity fixes, the `set_window_theme` switching action, `@MainActor`-isolated `Surface` lifecycle, "Close Split" in the right-click context menu, split activation & zoom indicator fixes, `copy-on-select` defaulting to the selection clipboard on macOS, paste protection for dragged text and carriage returns, Shortcuts duplicate-window prevention, `+ssh` `TERM` forwarding with remote `~/.terminfo` verification, and **Sparkle `2.9.6`**.
- **Session Runtime snapshot epoch rotation & Linux `libghostty-vt.so.1` packaging.** Rotates the binary session snapshot wire epoch to `7abe5365444c63ee8df6` for Ghostty 1.4's new Kitty graphics snapshot records (tags 8–10) and `ModePacked` bit 42 while preserving legacy `59c5cc7b4d1fe408faf5` session cutover mappings, updates Linux (`x86_64`, `aarch64`) remote `omgd` bundles and manifests to package `libghostty-vt.so.1` matching ELF `DT_NEEDED`, and ports `session-runtime` and **OMG Mobile (`iOS`)** `TermioStream` to the `libghostty-vt` 1.0 C API.

## Version and distribution

- OMG **0.22.0**, bundle version **62** (`CFBundleVersion`).
- Ghostty **1.4.1-dev**, revision `7a8ff4d992edd2aad7537e5bef73ec911aa126bf` (updated from `1.3.2-dev` `9ae02a326f62bd88f7f5508cf1807c67e7775cb5` in `v0.21.6`).
- Includes all upstream Ghostty and OMG changes since the published `v0.21.6` tag.
- macOS release apps and DMGs are **persistently self-signed (`OMG_SIGNING_MODE=self-signed`); not notarized**, using the same pinned release certificate and designated requirement across `OMG.app`, Sparkle helpers, `DockTilePlugin`, and nested `session-runtime` Mach-O binaries.
- **First-launch Gatekeeper & signer trust note**: Because apps and DMGs are not notarized, macOS Gatekeeper may block the first launch. Users who trust the downloaded app can review and allow it once in **System Settings → Privacy & Security**, and optionally install one-click Code Signing trust via **OMG → Settings → Plugins → OMG Doctor → Trust Release Signer for Updates** (or `omg +doctor`) to preserve TCC grants across updates (migrating from older ad-hoc builds may prompt once; never disable Gatekeeper globally). Sparkle updates retain their separate EdDSA signature on the `universal` DMG enclosure (`SUEnableAutomaticChecks` remains `false`).
- Each `arm64`, `x86_64`, and `universal` macOS app bundles `Contents/Resources/session-runtime` containing the universal local `omgd` relay, `omg-mobile-support`, `askpass`, `macos-aarch64` / `macos-x86_64` and `linux-x86_64` / `linux-aarch64` (`libghostty-vt.so.1`) remote session runtime artifacts, post-sign SHA-256 `manifest.json` files, `revision` (`ad43611eb342d95e271c`), and `snapshot-revision` (`7abe5365444c63ee8df6`). Existing remote `omgd` daemons owning live PTYs are never overwritten in place; older hosts without `durable-close/1` retain pending-close compatibility limits.
- iOS physical device installation requires signing with the user's own Apple ID (a free Personal Team Apple ID works via `OMG-Mobile-0.22.0-ios-installer.tar.gz`, or via SideStore / AltStore / Sideloadly using `OMG-Mobile-0.22.0-ios-unsigned.ipa` and `altstore-source.json`).
